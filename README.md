# My Portfolio & Academic Planner

CSC 106 (Introduction to Web Technologies) term project, MIVA Open University.

Prince Caleb Effiom, Software Engineering, 2024/B/SENG/0920

Live site: https://beladroid.github.io/cos106-portfolio/

It's a 5-page website made with plain HTML, CSS and JavaScript (no frameworks).

## Pages
- **Home** (`index.html`): my name and photo, a welcome message, a skills ticker, quick facts that count up, a short bio and recent projects
- **About** (`about.html`): education timeline, career goals, a skills table and hobbies
- **Projects** (`projects.html`): six of my projects in a bento grid, plus a video showreel
- **Planner** (`planner.html`): add tasks, mark them done, delete them and filter them. Tasks are saved in localStorage. There's a demo video too.
- **Contact** (`contact.html`): a contact form checked with JavaScript (no empty fields, valid email, phone number in digits only)

## Folders
- `css/style.css`: all the styling, including night/day mode and the phone layout
- `js/main.js`: night/day button, mobile menu, scroll reveal and the count-up numbers
- `js/planner.js`: the planner
- `js/contact.js`: form validation
- `images/` and `media/`: pictures and videos

To run it, open `index.html` in a browser.
