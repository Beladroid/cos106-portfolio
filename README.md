# My Portfolio & Academic Planner

COS 106 (Introduction to Web Technologies) term project, MIVA Open University.

Prince Caleb Effiom, Software Engineering, 2024/B/SENG/0920

It's a 5-page website made with plain HTML, CSS and JavaScript (no frameworks).

## Pages
- **Home** (`index.html`): my name and photo, a welcome message and a short bio
- **About** (`about.html`): education, career goals, a skills table and hobbies
- **Projects** (`projects.html`): six of my projects with screenshots and links, plus a video of the planner
- **Planner** (`planner.html`): add tasks, mark them done, delete them and filter them. Tasks are saved in localStorage.
- **Contact** (`contact.html`): a contact form checked with JavaScript (no empty fields, valid email, phone number in digits only)

## Folders
- `css/style.css`: all the styling, including the dark mode and phone layout
- `js/main.js`: dark mode button and mobile menu
- `js/planner.js`: the planner
- `js/contact.js`: form validation
- `images/` and `media/`: pictures and the planner video

To run it, open `index.html` in a browser.
